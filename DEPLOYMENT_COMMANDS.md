# Pizza Hut TV - Vercel Deployment Commands

# After installing Node.js, run these commands:

# 1. Install Vercel CLI
npm install -g vercel

# 2. Navigate to project directory
cd "c:\Users\toeng\Pizza Hut TV"

# 3. Login to Vercel
vercel login

# 4. Deploy to production
vercel --prod

# Alternative: Quick deploy (will ask for configuration)
vercel

# View your deployment
vercel ls
