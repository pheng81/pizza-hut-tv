================================================================================
        🎯 BOOTSTRAP SOLUTION - Implement Our Own Upload System
================================================================================

PROBLEM: We need to upload files, but the upload endpoint is in app.py which
         itself needs to be uploaded first! (Chicken and egg problem)

SOLUTION: Use the Pi as a bridge to bootstrap the process!

================================================================================
                        STEP-BY-STEP PLAN
================================================================================

PHASE 1: Bootstrap the Upload Endpoint (DO THIS FIRST)
-------------------------------------------------------
We need to get the NEW app.py onto the server so it has the upload endpoint.

The files are already on the Pi at:
- /tmp/new_app.py (the new app.py with upload endpoint)
- /tmp/new_dashboard.html (the dashboard with preview UI)

Method 1: Via RealVNC Terminal (EASIEST)
-----------------------------------------
1. Open RealVNC and connect to Pi
2. Open Terminal on Pi
3. Try to copy app.py to server:

   scp /tmp/new_app.py ubuntu@203.158.51.30:~/Pizza-Hut-TV/app.py

   If this works → You're golden! Continue with step 4.
   If this fails → The server is completely locked down. Try Method 2.

4. Restart server:

   ssh ubuntu@203.158.51.30 'sudo systemctl restart pizza-hut-tv'

5. Now the server has the upload endpoint! Jump to PHASE 2.


Method 2: Manual File Transfer (If Pi can't reach server)
----------------------------------------------------------
1. Open RealVNC and connect to Pi
2. Open Pi's file manager
3. Navigate to /tmp/
4. Copy new_app.py to a USB drive OR
5. Use RealVNC's file transfer feature to download to your PC
6. Use WinSCP to upload to server
7. Restart server

================================================================================
                        PHASE 2: Upload Dashboard HTML
================================================================================

Once the server has the NEW app.py with upload endpoint, we can use it!

Run the emergency uploader from your PC:

1. Open PowerShell in: c:\Users\toeng\Pizza Hut TV\

2. Run:
   python emergency_uploader.py

3. It will upload dashboard.html via HTTP API

4. Choose 'y' to restart server

5. Done!
