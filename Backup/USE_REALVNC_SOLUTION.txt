================================================================================
              METHOD 1: USE REALVNC + PI AS STEPPING STONE
================================================================================

Since RealVNC connects to Pi easily, and the files are already on the Pi,
you can use RealVNC to access the Pi, then upload from Pi to server!

STEPS:

1. CONNECT TO PI VIA REALVNC
   - Open RealVNC Viewer on your PC
   - Connect to: raspberrypi-ce39 (or whatever you use)
   - You'll see the Pi desktop

2. OPEN TERMINAL ON PI (via RealVNC)
   - Click the terminal icon on Pi desktop
   - OR: Press Ctrl+Alt+T

3. CHECK FILES ARE THERE
   Type: ls -lh /tmp/new_*
   You should see:
   - /tmp/new_dashboard.html
   - /tmp/new_app.py

4. UPLOAD FROM PI TO SERVER
   Copy these commands one by one:

   # Upload dashboard.html
   scp /tmp/new_dashboard.html ubuntu@203.158.51.30:~/Pizza-Hut-TV/templates/dashboard.html

   # Upload app.py
   scp /tmp/new_app.py ubuntu@203.158.51.30:~/Pizza-Hut-TV/app.py

   # Restart server
   ssh ubuntu@203.158.51.30 "sudo systemctl restart pizza-hut-tv"

   (When asked for password, enter the server password)

5. DONE! Now test in your browser:
   - Open: https://everydayadvertise.com/dashboard
   - Press Ctrl+Shift+R
   - Open Remote Pi Manager
   - Connect to Pi
   - See the 📺 Screen Preview!
   - Click ▶ Start
   - Screenshots appear!

================================================================================
           METHOD 2: DOWNLOAD FILES FROM PI VIA REALVNC
================================================================================

If Pi can't reach server either, use RealVNC to get files to your PC:

1. CONNECT TO PI VIA REALVNC

2. OPEN FILE MANAGER ON PI
   - Click folder icon on Pi desktop
   - Navigate to /tmp/

3. RIGHT-CLICK ON FILES
   - Right-click "new_dashboard.html"
   - Select "Transfer" or "Download" 
   - Save to your PC's Downloads folder
   
   - Right-click "new_app.py"
   - Transfer to your PC

4. NOW YOU HAVE FILES ON YOUR PC
   - Rename new_dashboard.html → dashboard.html
   - Rename new_app.py → app.py

5. UPLOAD TO SERVER USING WINSCP
   (See SIMPLE_GUIDE.txt for WinSCP steps)

================================================================================

1. CONNECT VIA REALVNC

2. OPEN BROWSER ON PI

================================================================================
              WHY REALVNC WORKS BUT SSH DOESN'T
================================================================================

Great question! Here's why:

RealVNC:
✅ Uses HTTPS tunneling (port 443)
✅ Goes through RealVNC cloud servers
✅ Bypasses firewalls easily
✅ Works from anywhere

SSH:
❌ Uses port 22 directly
❌ Often blocked by ISPs/firewalls
❌ Your network blocks it
❌ Server may only allow certain IPs

RealVNC is specifically designed to bypass network restrictions!
That's why it "just works" and SSH doesn't.
