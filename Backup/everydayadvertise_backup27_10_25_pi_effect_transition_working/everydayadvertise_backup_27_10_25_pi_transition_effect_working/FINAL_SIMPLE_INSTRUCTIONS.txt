================================================================================
                    HOW TO DO IT - 3 SIMPLE STEPS
================================================================================

STEP 1: Connect to Pi via RealVNC
----------------------------------
- Open RealVNC Viewer on your PC
- Connect to your Pi (like you always do)
- You'll see the Pi desktop

STEP 2: Open Terminal on Pi
----------------------------
- Click the Terminal icon (black screen icon) on Pi desktop
- OR press Ctrl+Alt+T

STEP 3: Run the Upload Script
------------------------------
Copy this command and paste into the Pi terminal:

python3 /tmp/pi_uploader.py

That's it! The script will:
1. Upload app.py to server (via HTTPS, not SSH!)
2. Upload dashboard.html to server
3. Restart the server
4. Show you the results

================================================================================
                        IF SOMETHING GOES WRONG
================================================================================

Error: "python3: command not found"
→ Try: python /tmp/pi_uploader.py

Error: "No module named 'requests'"
→ Run: pip3 install requests
→ Then try again

Error: "File not found"
→ The files are there! Try: ls -la /tmp/new_*
→ You should see the files

Error: "Connection refused" or "404"
→ The server doesn't have the upload endpoint yet
→ We need to copy app.py manually first (see BOOTSTRAP_PLAN.txt)

Can't connect via RealVNC:
→ Check Pi is powered on
→ Check both devices on same network
→ Try reconnecting

================================================================================
                    WHY THIS WORKS
================================================================================

This solution uses HTTPS (port 443) instead of SSH (port 22):
✅ HTTPS is never blocked
✅ Same protocol as RealVNC (that's why it works)
✅ Goes through firewall easily
✅ No SSH needed!

The Pi sends files to server via HTTP POST API
Server receives and saves files
Server restarts itself
Everything done through HTTPS!
