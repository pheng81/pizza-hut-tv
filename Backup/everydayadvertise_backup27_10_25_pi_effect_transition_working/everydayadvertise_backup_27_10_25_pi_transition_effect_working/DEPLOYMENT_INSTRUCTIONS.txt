TROUBLESHOOTING:
================

Preview section doesn't show:
- Server files not uploaded yet (dashboard.html)
- Browser cache not cleared
- Check browser console for errors (F12)

Pi not connecting:
- Check Pi is online: ping raspberrypi.local
- Check Pi logs: ssh everydayadvertise@raspberrypi "tail -f /tmp/pi_test.log"
- Restart Pi client (see Step 1)

Screenshots not appearing:
- Check Pillow installed: ssh everydayadvertise@raspberrypi "pip list | grep Pillow"
- Check scrot installed: ssh everydayadvertise@raspberrypi "which scrot"
- Check logs for "📸" messages

Server not restarting:
- Check service status: sudo systemctl status pizza-hut-tv
- Check logs: sudo journalctl -u pizza-hut-tv -f
- Manual restart: sudo systemctl stop pizza-hut-tv && sudo systemctl start pizza-hut-tv

- Sends screenshot requests every 2 seconds
