🍕 PIZZA HUT TV - PI INSTALLATION GUIDE
======================================

You have 3 ways to install Pizza Hut TV on your Raspberry Pi:

METHOD 1: One-Command Install (Easiest)
---------------------------------------
On your Pi terminal, run this single command:

curl -sSL https://raw.githubusercontent.com/pheng81/pizza-hut-tv/main/setup-pi.sh | bash

That's it! The installer will download and set up everything automatically.


METHOD 2: Using This USB Drive
------------------------------
1. Copy setup-pi.sh from this USB to your Pi home folder:
   cp /media/pi/*/setup-pi.sh ~/

2. Make it executable:
   chmod +x setup-pi.sh

3. Run the installer:
   ./setup-pi.sh

4. Follow the prompts


METHOD 3: Manual File Transfer
------------------------------
If you have network access to the Pi:

1. Download directly:
   wget https://raw.githubusercontent.com/pheng81/pizza-hut-tv/main/setup-pi.sh

2. Run installer:
   chmod +x setup-pi.sh && ./setup-pi.sh


AFTER INSTALLATION:
==================

1. Configure your server settings:
   nano ~/pizza-hut-tv-pi/phtv-config

2. Edit these values to match your setup:
   PHTV_SERVER="http://YOUR_SERVER_IP:5002"
   PHTV_STORE="YOUR_STORE_ID"
   PHTV_SCREEN="tv1"

3. Test manually:
   cd ~/pizza-hut-tv-pi && ./phtv-start

4. Enable auto-start:
   sudo systemctl enable pizza-hut-tv
   sudo systemctl start pizza-hut-tv

5. Check status:
   sudo systemctl status pizza-hut-tv


TROUBLESHOOTING:
===============

- View logs: journalctl -u pizza-hut-tv -f
- Restart: sudo systemctl restart pizza-hut-tv
- Stop: sudo systemctl stop pizza-hut-tv

The client will automatically:
- Connect to your Pizza Hut TV server
- Get slice video URLs for multi-screen setups  
- Use hardware-accelerated video playback
- Start automatically on Pi boot
- Recover from network issues

Need help? Check README_PI_SETUP.md for detailed documentation.
