Normal-user steps

1
Open this page on the Raspberry Pi
Use the Pi's browser to open this setup page. You can still click Download Installer, but the command below is the most reliable option because it downloads a fresh installer copy into /tmp before running it.
2
Run the installer command
Open Terminal on the Pi and run the command below. It does not rely on ~/Downloads and it auto-detects the normal desktop user to install the client under.
{{ local_command }}
3
Wait for the Pi to finish setup
The installer downloads the EverydayAdvertise TV client, installs dependencies, creates the auto-start service, and preloads the chosen store and screen.
4
Check Pi Manager
After a minute or two, refresh Pi Manager. The new Pi should appear with its new Pi ID and should already be assigned to {{ screen_name }}.

If something goes wrong

A
Check the service
Run sudo systemctl status everydayadvertise_tv on the Pi.
B
Check the logs
Run journalctl -u everydayadvertise_tv -f and watch for errors.
