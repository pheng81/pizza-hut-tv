TROUBLESHOOTING:
───────────────

❓ Command not found?
   Try: python /tmp/pi_uploader.py
   (without the "3")

❓ No module named 'requests'?
   Run: pip3 install requests
   Then try the command again

❓ Can't connect to RealVNC?
   - Check Pi is powered on
   - Check network connection
   - Try restarting RealVNC Viewer

❓ Terminal won't open?
   - Look for an icon that looks like >_ or a black square
   - Try right-clicking desktop → Terminal
   - Or look in applications menu

❓ Upload fails?
   - Check Pi can reach internet: ping google.com
   - The files are there: ls -la /tmp/new_*


WHAT THIS DOES:
───────────────

Your PC → RealVNC → Pi Desktop → Terminal → Run Python Script →
Script reads files from /tmp/ → Sends via HTTPS to server →
Server saves files → Server restarts → Preview feature active!

No SSH! No blocked ports! Uses HTTPS (port 443) which always works!
